Console Admin — CrowdLuma Stadium Choreo

Créer un show de tribune depuis une photo, un logo ou une vidéo, puis exporter un fichier JSON utilisable par la web-app supporters/régie.

1. Configuration club / tribune

2. Source visuelle

La vidéo est échantillonnée en plusieurs images. Pour un stade, mieux vaut des formes simples, contrastées, sans détails fins.

3. Palette

MVP1 : palette fixe. Phase suivante : palette personnalisable club/sponsor.

4. Services / Menu participants

Activez les services visibles sur le téléphone des supporters pendant le match. Ces choix sont inclus dans le JSON exporté.

5. Export

Le fichier JSON peut ensuite être importé dans index.html ou publié dans le repository GitHub Pages.

Prévisualisation des frames

Aucune frame générée.

Workflow recommandé pour un club

  1. Ouvrir admin.html.
  2. Entrer tribune/bloc/rangées/sièges.
  3. Importer logo, image ou vidéo.
  4. Vérifier la prévisualisation basse résolution.
  5. Exporter show.json.
  6. Importer ce JSON dans la web-app régie/supporter ou le publier avec GitHub Pages.
  7. Générer les QR codes par siège depuis l’URL publique réelle.

MVP1 sans backend : aucun upload serveur. Tout est traité localement dans le navigateur. Pour une vraie administration multi-utilisateurs, il faudra ajouter plus tard une couche GitHub commit/API, Supabase/Firebase, ou un petit backend.
