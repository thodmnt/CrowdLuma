# CrowdLuma
CrowdLuma transforme les tribunes en écran géant : chaque spectateur scanne un QR code sur son siège, son smartphone affiche la bonne couleur au bon moment, créant une chorégraphie lumineuse collective. Sans app à installer. Open source, il intègre aussi commande de boissons et votes en temps réel.​​​​​​​​​​​​​​​​
